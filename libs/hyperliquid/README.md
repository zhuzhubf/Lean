# Hyperliquid SDK Integration

Add your forked SDK as a git submodule here to preserve provenance and LICENSE information:

```bash
git submodule add https://github.com/<GITHUB_OWNER>/hyperliquid-python-sdk-fork.git libs/hyperliquid/hyperliquid-python-sdk
```

The SDK should only be used for read-only probes until live-trading guardrails and risk controls are implemented.
